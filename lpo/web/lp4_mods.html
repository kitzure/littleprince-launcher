Sign in first

Mods write saved progress, so the server asks you to sign in on the accounts page, then come back here.

How these apply

Changes go to this account's 星願思語 save and the game reads them at its next login: log out of the game (or reload its page) after changing something. Each field remembers the value it had before its first change, so Restore puts the save back exactly.

Presets

Coins and licence

Coins pay for battles and the shop. The licence decides how many difficulty levels and war maps the game offers (HAVE_SERIAL_PERSON is everything).

Mini-game difficulty

The highest difficulty each mini-game has opened: 1 簡單, 2 容易, 3 中等, 4 複雜, 5 困難, 6 特別.

Soldiers

The allies who fight in the battle maps. Ticked = unlocked; their experience is kept. The first one is always with you.

Shop bag

How many of each item the account holds (0-999).
