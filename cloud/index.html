星夜重圓 needs the Android emulator

星夜重圓 was only released for Android and iOS, so the launcher plays it in Google's Android emulator. It will download from dl.google.com into %LOCALAPPDATA%\Android\Sdk: . Then it fetches the game itself from the publisher's server.

Google's Android SDK licence terms below apply to those packages. Nothing is downloaded unless you accept them.
