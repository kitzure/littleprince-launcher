LITTLE PRINCE LAUNCHER — WINDOWS v1.2
Setup, how it works and support guide

Website: https://kitzure.github.io/littleprince-launcher/
Repository: https://github.com/kitzure/littleprince-launcher

QUICK START
1. Download the Windows ZIP and extract it into a new writable folder.
   Do not launch it inside the ZIP.
2. Double-click Little Prince Launcher.exe. Accept the administrator
   prompt for the hosts redirect and port-80 service. Python is
   bundled; nothing else needs installing.
3. Choose a game and press Play once. A missing game or game browser
   is downloaded first (one progress bar), then the game opens.
   星夜重圓 asks once for Google's Android SDK licence, then sets up
   its emulator and starts.
4. Create a local account under Accounts at the bottom of the
   launcher window, use it in the game, and keep the launcher open.
   Close the window normally when finished.
For original CD installations, back up the original files first and
use the supplied patches in the launcher's app\patches folder.

modern character artwork does not change the supported game list.

HOW IT WORKS
The launcher temporarily redirects relevant classic-game hostnames
to this computer and starts local services for the games' AMF calls.
Default ports:
- 80: CD-game service and hosts redirect.
- 8080: game portal, account website and online-game gateway.
- 8443: local multiplayer relay when enabled.
Implemented game requests are handled locally; supported account,
progress and score records are saved in the installation folder.
Supplied patches adapt classic-client license checks and selected
client behavior for this local setup.
Normal settings answer unknown services locally rather than sending
them to the publisher. Game/browser downloads still use the internet.
Normal shutdown stops services and removes the added hosts entries.
After a forced termination, use Revert hosts in the server menu.

LOCAL FEATURES
- Local accounts, profiles and available worlds.
- Supported progress saves and per-title leaderboards.
- Friends/mail between local accounts, and an editable notice board.
- Accounts and Mods open inside the launcher window.
- Per-game mod presets/fields, normally applied at the next login.
- Server status and request logs.
- Lobby/room handling; full multiplayer behavior is not guaranteed.
These are local records, not the publisher's or a school's accounts.

REQUIREMENTS
- Windows desktop/laptop; no guarantee for old Windows or ARM/emulation.
- Nothing to install: Python is bundled in app\runtime. The window
  uses the Edge WebView2 Runtime built into Windows 11 / current 10.
- Administrator rights for hosts redirection and port 80.
- Free local ports and a writable installation folder.
- Internet and additional disk space for missing browser/game files.
  The launcher ZIP is not the complete game collection; individual
  downloads can be hundreds of megabytes.
- Starwish Reunion: hardware virtualization (Windows Hypervisor
  Platform) and about 5 GB for the Android emulator and the game.
- Game copies you legally own. No official key/subscription is supplied.

DATA AND SAFETY
Back up the installation folder before updating. Do not publish its
personal account files, passwords or unredacted logs.
Create a separate local password; do not reuse email/school passwords.
Follow the Accounts site's validation for the legacy password fields.
Servers may listen on network interfaces, not only localhost.
Keep Windows Firewall enabled. Do not forward the local service ports
on a router or expose this installation to the public internet.
Installer sources are Catbox, Pixeldrain or trusted self-hosted HTTP(S).
Google Drive installer URLs and redirects are disabled.

LIMITATIONS
- The launcher is Windows-only, not a macOS/Linux/Android/iOS app.
- Legacy Flash compatibility varies. The offered game browser is the
  compatibility path; Ruffle may render or behave differently.
- Local server recreation is partial. Some original functions, asset
  requests and multiplayer modes may differ or fail.
- No official matchmaking, school-account import, subscription or
  cloud account synchronization is provided.
- Offline play is not guaranteed for every mode or missing asset.
- This project is not affiliated with the original publisher.

TROUBLESHOOTING
SmartScreen warning: the exe is not code-signed. Check the checksum
below, then choose More info, Run anyway.
Window does not open: unzip the whole folder (the exe needs
WebView2Loader.dll and app\ beside it); on older Windows 10 install
the Edge WebView2 Runtime. See %TEMP%\littleprince-launcher.log.
Admin prompt cancelled: reopen the exe and accept the prompt for the
full hosts/CD setup; port 80 and redirects may fail without elevation.
Port conflict: close other launchers/apps using that port. Read the log.
Advanced local testing (source checkout, Python 3 with Tkinter):
python Start_Server_GUI.pyw --no-hosts --port 18080
That test command does not enable the normal CD hostname redirect.
Official site opens: keep the launcher running, verify hosts redirect,
and use the game browser. DNS-over-HTTPS can bypass the redirect.
Download failure: check network, disk and logs; select a permitted
mirror or trusted self-hosted pack. A launcher mirror is not a
replacement for a broken individual game-pack URL.
Redirect remains after a crash: use Revert hosts. Back up
the hosts file before manual edits.
Mod missing: check the title/account, then log out and enter the game
again. Changes are normally sent by the local server at login.
Report unresolved issues at the repository's Issues page. Remove
personal details and passwords from log excerpts before posting.
