01 / Quick start

  1. Download the Windows ZIP. Extract it into a new folder you can write to. Do not run the launcher inside the ZIP.
  2. Double-click Little Prince Launcher.exe. Accept the administrator prompt so the launcher can set up the local hosts redirect and its port-80 server. Python comes bundled in the ZIP; there is nothing else to install.
  3. Choose a game and press Play once. If the game or the publisher's Flash-capable browser is missing, the launcher downloads it, shows one progress bar, then opens the game. 星夜重圓 asks once for Google's Android SDK licence, then sets up its emulator and starts.
  4. Create a local account under Accounts at the bottom of the launcher window, then use that account in the game. Keep the launcher open while playing; close it normally when finished.

Using an original CD installation instead? Back up its files first, then use the supplied patches in the launcher's app\patches folder. This is separate from downloading a game through the portal.

02 / Supported games

The launcher supports these six titles: the four classics, plus 星願思語 (LP4) and 星夜重圓 Starwish Reunion (LP5) since v1.1. “Supported” describes the local launcher/server integration, not a guarantee that every original mode or service is complete.

LP1

Little Prince

Classic game access through the portal, local account/progress handling and per-title mod presets. Patches for the original CD version are also included.

LP2

Starwish Legend

The same local portal and account/progress integration, with game-specific fields and CD-version patches.

LP3

Prince Adventure

Local accounts/progress, title-specific presets such as card unlocks, and CD-version patches.

LPO

Little Prince Online

A local replacement server, account management, worlds, saves, local friends/mail and leaderboards. Lobby/room handling is included; full multiplayer behavior is not guaranteed.

LP4

星願思語 · 星空聯盟

New in v1.1. The publisher's web build, opened from its own portal card. Its textures, music, question banks and battle data are downloaded from the publisher the first time you play; login, saves, high scores, the shop and ranks run on the local server, and new players get the full licence (all difficulty levels). Plays in the publisher's Flash browser.

LP5

星夜重圓 Starwish Reunion

New in v1.1. The publisher's Android app, run on this PC: pressing Play sets up a local Android emulator (Google's SDK, after you accept its licence), builds a patched APK from the publisher's own copy and serves the game's accounts, progress and level downloads locally. A Reunion mods page edits unlocked games, levels, ranks, gold, stones and stamina. For phones, see the Android APK.

Not included: the newer Starwish Party app, LP4's classroom/teacher mode, official account synchronization, and macOS/Linux/mobile launcher builds. The website's modern artwork is a presentation choice, not support for the newer app.

03 / How it works

Classic game→Local game services→Your local records

The old games expect the publisher's server addresses. The launcher temporarily redirects the relevant hostnames to your computer and starts local services that answer the games' AMF requests.

  • Port 80: the local CD-game service and hosts redirect.
  • Port 8080: the game portal, account website and online-game gateway.
  • Port 8443: the local multiplayer relay, when enabled.

Local services handle the implemented login, progress, mail, friends and ranking requests. Supplied patches adapt the classic clients' license checks and selected client behavior for this local setup.

Normal launch settings answer unknown services locally instead of forwarding them to the publisher. Missing game/browser downloads still use the internet. This is not the publisher's official live service.

On a normal shutdown, the launcher stops its services and removes the hosts entries it added. If it was force-closed, use Revert hosts in its server menu.

04 / Local tools

  • Accounts: create and manage local players, profiles and available worlds, inside the launcher window.
  • Saves and rankings: record the supported progress/score fields, with scores separated by title.
  • Friends, mail and notice board: use local accounts and edit the castle's notice board.
  • Mods: also inside the launcher window. Choose the game first, then apply its supported presets or fields. Changes normally appear at the next game login.
  • Status and logs: inspect running services and request messages in the launcher.

These are features of your local installation. They do not import a school's or the publisher's existing account history.

05 / Requirements

Computer
A Windows desktop or laptop. Use a current Windows installation; compatibility with old Windows releases or ARM/emulation is not guaranteed.
Python
Bundled. The ZIP carries its own Python runtime in app\runtime; an installed Python is not needed.
Window
Microsoft Edge WebView2 Runtime, which Windows 11 and current Windows 10 already include.
Permissions
Administrator rights for the hosts redirect and port-80 service. Free local ports are needed for the services above.
Starwish Reunion
Hardware virtualization (Windows Hypervisor Platform) for the Android emulator, and about 5 GB for the emulator, its Android 9 system image, the emulated phone and the game.
Downloads
Internet access for missing browser/game files. The launcher ZIP is not the full game collection; individual client downloads may be hundreds of megabytes.
Storage
A writable folder with space for the launcher, downloaded clients and saves. Keep backups before replacing a game or launcher folder.
Game ownership
Use only copies you legally own. No official serial key, subscription or publisher account is supplied.

06 / Your data & safety

Accounts, supported saves and other local records are written into your installation folder. Back that folder up before updating or reinstalling, and never upload your personal account files with a bug report.

Use a separate local password, not your email, school or another service's password. The legacy game has short password-field limits; follow the Accounts site's validation.

The services can listen on network interfaces, not only localhost. Keep Windows Firewall enabled. Do not expose these ports to the public internet or forward them on your router; this is not a hardened public hosting service.

Installer sources use Catbox, Pixeldrain or custom HTTP(S) self-hosted URLs. Google Drive installer links and redirects are disabled.

07 / Limitations

  • Windows launcher only. This website is mobile-readable; the games/launcher are not Android, iOS, macOS or Linux applications.
  • Legacy Flash software. Use the offered game browser for compatibility. Ruffle is available for browser playback, but rendering and some modes may differ.
  • Partial server recreation. Some original game functions, asset requests and multiplayer modes may not work exactly as they did on the official server.
  • No official online service. Public matchmaking, school accounts, official subscriptions and cloud account synchronization are not provided.
  • No universal offline promise. Missing assets need downloading; offline behavior depends on the installed files and game mode.

08 / Troubleshooting

Windows says it protected your PC

The launcher is not code-signed, so SmartScreen may warn about it. Check the ZIP's checksum below, then choose More info → Run anyway.

The launcher window does not open

Unzip the whole folder: the exe needs WebView2Loader.dll and the app folder beside it. On older Windows 10, install Microsoft's Edge WebView2 Runtime. Startup problems are written to %TEMP%\littleprince-launcher.log.

The administrator prompt is cancelled

Reopen Little Prince Launcher.exe and accept the prompt if you want the full hosts/CD setup. Without elevation, port 80 and the hosts redirect may not work.

A server port is already in use

Close a second launcher instance or another application using the same port. Check the log for the exact port. From a source checkout with Python 3 and Tkinter, advanced testing can use python Start_Server_GUI.pyw --no-hosts --port 18080, but that does not enable the CD games' normal hostname redirect.

The game opens the official website instead

Keep the launcher running and check that its hosts redirect is active. Use the offered game browser. A browser's DNS-over-HTTPS setting may bypass the local redirect; disable it for this setup if necessary.

The game download fails

Check your connection, free disk space and the launcher log. Try a permitted mirror or a trusted self-hosted pack URL through download settings. Changing the launcher download mirror does not replace a broken individual game pack.

Game domains still point to localhost after closing

Reopen the launcher and use Revert hosts in its server menu (bottom right). A crash, forced termination or power loss can prevent normal cleanup. Back up the hosts file before making any manual changes.

A mod value does not appear in the game

Confirm the selected title and account, then log out and re-enter that game. Mod changes are returned by the local server on login, not necessarily applied to a running session.

For unresolved problems, describe the game, the steps and the relevant log excerpt in GitHub Issues. Remove account details, passwords and personal file paths first.

10 / Starwish Reunion (Android)

星夜重圓 Starwish Reunion v1.13.0, the publisher's Android app, repackaged so it installs and runs on newer phones. It still uses the publisher's own server: sign in with your existing Starwish account (or tap Start as before). The game code is unchanged.

What was changed, and nothing else:

  • The separate OBB data file is built into the APK, so there is one file to install (Android 11+ no longer lets you copy files into Android/obb).
  • Target SDK raised from 23 to 24, which Android 15 requires before it will install an app.
  • The phone-state permission is removed. On Android 10+ it no longer reaches the phone ID, and the old app then gave every phone the same device ID, which signed different players into one account. Your device ID now comes from your own phone.
